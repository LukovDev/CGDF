# Документация по `cgdf/core` (cgdf-v1.0.0-beta)

### Что из себя представляет
Является базовой библиотекой программы. Так называемый "набор инструментов" из самых необходимых функций и реализаций, которые сильно упрощают дальнейшую разработку и часто используются. Аналогия: Базовая стандартная библиотека Python, или базовая библиотека C++, которые предоставляют часто используемый полезный функционал.

### Структура
Является независимым пакетом (каталогом) который встраивается в исходный код. Является источником целей для компиляции и подключения, по этому его обязательно надо указать как цель сборки и подключения в системе сборки.

Структура должна выглядеть так:
- `core/` - Сама библиотека.
    - `libs/` - Подкаталог зависимостей и библиотек. Игнорируйте.
        - `cglm/` - Библиотека GLM под язык Си.
        - `stb_`... - Маленькие реализации функционала.
        - `tiny`... - Маленькие реализации функционала.
    - `array.c` `array.h` - Динамический массив.
    - `core.h` - Ядро. Подключает весь функционал модуля через себя.
    - `default_icon.bin` - Сырые данные (байты) иконки по умолчанию.
    - `files.c` `files.h` - Простая работа для чтения и записи файлов.
    - `hashtable.c` `hashtable.h` - Хэш-таблица.
    - `info.c` `info.h` - Получение подробных данных о процессоре и озу.
    - `jobsystem.c` `jobsystem.h` - Простая система задач (на основе потоков).
    - `libs.h` - Подключает через себя все что внутри `libs/`
    - `logger.c` `logger.h` - Простой логгер информации в консоль и файл.
    - `math.h` - Подключает `CGLM` и `math.h` через себя, а также реализует какой-то функционал.
    - `mm.c` `mm.h` - Менеджер памяти. Единый способ для работы с памятью.
    - `node.c` `node.h` - Система дерева из узлов, на основе ленивого дерева.
    - `noise.c` `noise.h` - Простые функции шума.
    - `pixmap.c` `pixmap.h` - Работа с растровыми картинками.
    - `platform.h` - Определяет на какой платформе работает программа.
    - `std.h` - Собирает все базовые `<std>` заголовки через себя.
    - `time.h` - Работа со временем.

Рассмотрим каждый из них:

### Array
Описание, демонстрация работы с динамическим массивом, подробная информация, примеры, как полностью протестировать (тесты чтобы выявить ошибки), и так далее. Описание короче.

тоже самое с Files, HashTable, Info, JobSystem, Logger, Math, mm, Node, Noise, Pixmap, Platform, Time.
